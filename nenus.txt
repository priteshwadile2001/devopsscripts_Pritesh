6.passwd nexus
7.sudo visudo 
add the line
nexus ALL=(ALL) NOPASSWD: ALL -- Giving full permission to nexus user

8.sudo chown -R nexus:nexus /opt/nexus
9.sudo chown -R nexus:nexus /opt/sonatype-work/
10.cd /opt/nexus/bin/
11. echo 'run_as_user="nexus"' > /opt/nexus/bin/nexus.rc


This file doesn't control CPU. It only sets memory for the Java process, and Nexus uses whatever CPU cores the instance has. The only way to get more CPU is a bigger instance type. If your goal is to make Nexus faster or stop it crashing, raise the memory with the first three lines.

12. vi nexus.vmoptions

-Xms1024m
-Xmx1024m
-XX:MaxDirectMemorySize=1024m

-XX:LogFile=./sonatype-work/nexus3/log/jvm.log
-XX:-OmitStackTraceInFastThrow
-Djava.net.preferIPv4Stack=true
-Dkaraf.home=.
-Dkaraf.base=.
-Dkaraf.etc=etc/karaf
-Djava.util.logging.config.file=/etc/karaf/java.util.logging.properties
-Dkaraf.data=./sonatype-work/nexus3
-Dkkaraf.log=./sonatype-work/nexus3/log
-Djava.io.tmpdir=./sonatype-work/nexus3/tmp


13.sudo vi /etc/systemd/system/nexus.service

[Unit]
Description=Nexus Service
After=network.target

[Service]
Type=forking
LimitNOFILE=65536
ExecStart=/opt/nexus/bin/nexus start
ExecStop=/opt/nexus/bin/nexus stop
User=nexus
Restart=on-abort

[Install]
WantedBy=multi-user.target
