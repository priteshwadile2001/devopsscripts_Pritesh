1. Install Java

Tomcat 10.1 needs Java 11+, and Java 21 (which you already have for Jenkins) works fine:

bash
sudo dnf install -y java-21-amazon-corretto
java -version


2. wget https://downloads01-he-fi.apache.org/tomcat/tomcat-10/v10.1.60/bin/apache-tomcat-10.1.60.tar.gz
tar -xzvf apache-tomcat-10.1.60.tar.gz


3.add user

          <role rolename="manager-script"/>
